# AI Launchpad Pro

Create a high-converting, modern, and ultra-fast AI Agency Website for my company "HN Group" (www.hn-groupe.org). The website serves as a showcase for our achievement of building over 200+ full-stack web applications using Lovable, and acts as a funnel to acquire new clients wanting fast web development, hosting, and prompt engineering consulting.

Use a dark, sleek, futuristic UI theme (similar to Vercel/Linear), with glowing purple and cyan accents, glassmorphism, smooth animations, and interactive elements.

Include the following structured sections:

1. HERO SECTION:
- Main Headline: "Launch Your Digital Product in Hours, Not Months."
- Sub-headline: "Powered by AI & Proven Expertise. Over 200+ Production Web Apps and Custom Domains Deployed."
- Dynamic Animated Stats Counter: 
  * 200+ Custom Domains Active
  * 24-48h Average Delivery Time
  * 99.9% Uptime & Full Stack Integration
- Dual CTAs: "Book a Demo / Project" (Primary Button) and "Explore Portfolio" (Secondary Ghost Button).

2. LIVE PORTFOLIO & CASE STUDIES (Interactive Showcase):
- A categorized gallery with filter tabs: "SaaS & Tools", "E-Commerce", "Enterprise Solutions", "AI Prototypes".
- Responsive grid cards showing project screenshots, tags (React, Supabase, Tailwind, Custom Domain), and a live interactive preview button.

3. SERVICES & FEATURED PACKAGES (Comparison Table):
- Package 1: "Express Launch" (For Startups/MVPs - 24-48h Delivery, Domain Setup, UI Design).
- Package 2: "Full-Stack Pro" (For Growing Businesses - Database/Supabase, API Integration, Payment Setup, 1 Month Support).
- Package 3: "Managed Subscription" (Monthly Host + AI Maintenance & Weekly Updates).

4. INTERACTIVE PRICE ESTIMATOR (Cost Calculator):
- A step-by-step widget where visitors select:
  1) Type of project (Landing Page / Web App / SaaS / E-Commerce)
  2) Database needed? (Yes / No)
  3) Custom Domain included? (Yes / No)
- Calculates a real-time price range and features a "Send Order via WhatsApp / Email" action button.

5. PROMPT ENGINEERING & CONSULTING SECTION:
- A dedicated block for developers/enterprises offering 1-on-1 consulting, team training, and prompt optimization for Lovable power users.

6. FOOTER & CONTACT:
- Full contact details: Moulay Ismail EL HASSANI, HN Group (info@hnchat.net, www.hn-groupe.org).
- Integrated contact form and direct WhatsApp chat floating icon.

Ensure all components are fully responsive (mobile-first), highly accessible, and use Clean Tailwind CSS with Lucide React icons.
